Thank you for contributing to this project!

Branching & PRs
- Create a feature branch named `type/short-description` (e.g., `docs/add-contributing`).
- Open a PR against `main` and include a short description of the change.

Commit messages
- Use imperative style, e.g. `docs: add CONTRIBUTING guide`, `fix: improve loader`.

Testing & linting
- Run unit tests with `pytest` and lint with `flake8` before opening a PR.

Small changes
- Prefer small, focused PRs to make review easier and to generate contribution events.

Code style
- Follow existing project conventions (PEP8). Keep changes minimal and well-tested.
