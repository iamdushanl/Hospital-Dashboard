# Modern Hospital Analytics Dashboard

Real-time hospital data insights powered by large tabular ML models.

## Features
- **Real-time Metrics**: Patient counts, readmission rates, OPD visits
- **Interactive Charts**: Trends, department loads, risk distribution
- **AI Insights**: Powered by TabPFN, CatBoost, XGBoost ensemble
- **Beautiful UI**: Modern gradient design with Tremor React

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deploy to Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/yourusername/hospital-analytics)

Or using CLI:
```bash
vercel --prod
```

## Tech Stack
- Next.js 14
- React 18
- TypeScript
- Tremor React
- Tailwind CSS

Built for deployment on Vercel with zero configuration needed!
